# ADR-0001：以私有仓库保存完整项目基线

- 状态：accepted
- 日期：2026-08-28

## 背景

用户要求把项目完整上传到 GitHub。仓库包含生成视频、第三方研究归档、项目素材和可能与本地运行环境相关的配置示例，公开可见性尚未明确。

## 决策

创建 `Exalex` 名下的私有 GitHub 仓库，并保留源码、文档、研究资料、压缩包和生成资产。仅排除缓存、虚拟环境、本地环境变量和私钥等不应版本化的文件。

## 原因

- 满足“完整上传”的要求；
- 私有仓库降低研究资料和项目素材意外公开的风险；
- 单文件目前低于 GitHub 100 MB 限制，可先保留完整基线；
- 后续若要开源，可再按许可证和体积拆分。

## 影响

- 首次 clone 体积较大；
- 第三方目录的许可证仍需按原项目分别遵守；
- 生成视频和归档包会增加 Git 历史体积，后续可迁移 Git LFS 或 Release Assets。
