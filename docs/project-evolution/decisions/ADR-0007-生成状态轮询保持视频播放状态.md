# ADR-0007 · 生成状态轮询保持视频播放状态

## 背景

生成弹窗每 5 秒刷新任务状态；此前通过 innerHTML 重建 video 元素，播放到中途会回到 0 秒，且自定义 click 与原生 controls 存在双重切换风险。

## 决策

状态轮询只更新日志、状态和进度；同一媒体 URL 复用已有 video 节点，播放交互交给原生 HTML5 controls。

## 备选方案

- 每次轮询都重新渲染整个生成行，代码更简单但会重置播放位置；继续使用自定义 click 切换则可能与 controls 产生双重播放/暂停。

## 后果与权衡

- 播放位置和缓冲状态在轮询期间保持，点击预览行为与浏览器一致；视频 URL 真正变化时仍会创建新节点并重新加载。
