# ADR-0004 · 以项目为入口并按集隔离工作空间

## 背景

用户需要在导演台中先切换完整项目，再按集管理简案、资产、分镜和生成产物。旧界面只提供单层项目选择，无法表达项目内集数边界。

## 决策

将 projects/*/project.json 作为项目清单入口，将 episodes/*/episode.json 作为实际工作空间；前端左栏嵌套显示项目与集数，中央和右侧全部绑定当前 episode，生成产物写入集内 outputs。

## 备选方案

- 继续用单层项目下拉框，把不同集数混在同一份项目 JSON 或依靠文件名区分。

## 后果与权衡

- 项目切换和集数切换都会重载完整工作台；每集可独立保存素材、提示词和视频，旧项目 JSON 需要迁移到 episode.json；后端继续保留受限相对路径和旧 gen 回退兼容。
