# ADR-0008 · 生成进度按可观察阶段展示并标注估算

## 背景

ComfyUI 当前接口只能可靠提供队列 pending/running 和 history 完成状态，不能提供当前节点的精确百分比；前端原有三阶段进度无法解释排队、GPU 生成和下载，也没有剩余时间提示。

## 决策

任务 API 增加 phase 与 percent，单镜生成按准备、排队、GPU 生成、下载、完成五个可观察阶段更新；前端显示队列位置、已耗时和基于当前阶段的预计剩余时间，并明确标注估算。

## 备选方案

- 继续用 cur/total 三阶段或伪造精确 GPU 百分比，界面更简单但会掩盖排队和下载耗时并造成错误预期。

## 后果与权衡

- 用户能区分等待 GPU、实际生成和下载，任务完成时显示 100%；进度和 ETA 对首次运行或远端重启任务仍是阶段估算，不能替代 ComfyUI 节点级真实进度。

## 复审条件
