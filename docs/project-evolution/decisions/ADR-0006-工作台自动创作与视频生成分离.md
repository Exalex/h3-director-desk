# ADR-0006 · 工作台自动创作与视频生成分离

## 背景

用户希望在工作台输入一句故事创意后自动完成简案、资产、分镜等前期流程，同时项目连接远端 ComfyUI/H3。

## 决策

新增异步 chat_workflow 任务，串联 Qwen 项目 JSON、资产规划文件、每镜提示词编译和分镜自检；视频生成继续由制作计划显式逐镜提交。

## 备选方案

- 在自动创作任务中直接批量提交 ComfyUI 视频任务，流程更短但成本、排队和重复生成风险更高。

## 后果与权衡

- 输入创意后可看到 1/5 到 5/5 的进度和最新日志，生成结果可直接进入后续阶段；资产图片仍需单独生成或补充，远端 GPU 不会被文字输入意外占用。

## 复审条件

- 关键假设失效；
- 性能、可靠性、安全或维护成本不再满足目标；
- 出现更低成本且兼容的替代方案。
