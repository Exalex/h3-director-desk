# ADR-0005 · 生成任务以 ComfyUI 远端队列为幂等边界

## 背景

导演台生成请求返回已提交后，用户可以重复打开窗口并再次提交；服务重启还会清空内存任务表，但远端 ComfyUI 任务仍可能运行。

## 决策

生成前同时检查导演台任务表和 ComfyUI /queue，并按 SaveVideo.filename_prefix 对镜头去重；前端显示并定时刷新提交中、队列中、处理中、完成和失败状态。

## 备选方案

- 只依赖浏览器按钮禁用或只依赖导演台内存任务表

## 后果与权衡

- 避免同镜头重复占用 GPU，并让服务重启后仍能识别远端队列；队列识别按镜头文件名前缀匹配，旧任务缺少集路径时存在跨集同名镜头的保守拦截风险。

## 复审条件

- 关键假设失效；
- 性能、可靠性、安全或维护成本不再满足目标；
- 出现更低成本且兼容的替代方案。
