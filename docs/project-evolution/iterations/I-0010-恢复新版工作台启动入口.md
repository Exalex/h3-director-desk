## 验证证据

- 新版首页标题为“导演台 · 项目工作台”；/api/hardware 返回 base=http://192.168.3.75:8188、online=true；ComfyUI 0.31.0、NVIDIA GB10；首页 HTTP 200；node --check、py_compile、git diff --check 通过。
