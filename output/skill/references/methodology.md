# 爆款方法论（methodology）

> 来自 Short-Drama-Concept-Creator + ai-script-hub。核心：把爆款规律变成**可执行判断框架**，不是提示词。

## 调性检验（判对没错）
- ✅ "天哪她好厉害，我也想这样" → 对
- ❌ "唉她好惨，但还好她挺过来了" → 错（苦情不是短剧）
- 短剧是成人童话：观众是来看自己的苦被解决的。

## 三幻想来源（从幻想开始，不从问题开始）
能力幻想（她太强了）/ 身份幻想（普通外表藏惊人另一面）/ 行动幻想（先动手了）。

## 喜剧公式
`奇幻触发器 × 极端身份错位 × 家庭/情感关系 × 喜剧 × 治愈`（≥3/5 要素）。

## 大女主原则
CP 是调味料不是主菜；主引擎是"看她怎么做"，不是"他俩在一起了吗"。

## 五黄金法则（system prompt 级）
1. 竖屏思维：半身/特写为主，避免大场景全景
2. 节奏：每 15-20s 一个情绪点，每集 ≥3 高潮
3. 对白：简洁，一句 ≤20 字
4. 爽点密集：打脸/反转/告白/揭秘交替
5. 结尾钩子：最后一句/画面必是悬念

## 女主三关
配得感（本来就值得）/ 快意恩仇（当场怼回，不隔夜）/ 主体性（她做选择，不是被选择）。

## 标题 5 铁律
情绪承诺 / 反差 / 动词 / 4 字或长句（避 6-8 字中间地带）/ 迭代高频词（总裁/夫人/重生 已疲劳）。

## 5 题材节奏模板
| 题材 | 要点 |
|---|---|
| 都市逆袭 | 开头3s冲突/悬念/打脸；每集≥2反转；弱势→强势；15-20s一爽点；结尾钩子 |
| 甜宠言情 | 第1秒建CP张力；甜-虐-甜；每集1名场面；结尾矛盾爆发/误会 |
| 悬疑惊悚 | 开局命案/失踪/诡异；每集≥1反转；线索+误导；结尾更大谜团 |
| 穿越重生 | 30s内交代设定；降维打击；每集解决一个前世遗憾 |
| 甜宠先婚后爱 | 开场契约婚姻场景；假戏真做；吃醋/护妻/心动 |

## 3 节奏开关
- `hot`(爆款)：开头5s高能钩子，每15s情绪引爆点
- `short`(精简)：台词≤15字，8-10s切场，多特写快切
- `long`(深度)：铺垫更长情感线，单集1200-1500字

## 15 字段概念 schema（可直接当 LLM 输出格式）
```
### 概念X:《片名》
奇幻触发器 / 她是谁 / 她做什么 / 极端身份错位 / 高概念 / 一句话梗概 /
喜剧引擎 / 家庭情感线 / 女主三关(配得感✓✗|快意恩仇✓✗|主体性✓✗) /
CP磕点 / 每集结构(开场钩子→中段冲突→结尾悬念) / 开场钩子 / 风险提示
```

## 生成链（两段）
概念层：受众+题材+情绪标签 → LLM(方法论当 system prompt) → 3 个差异化概念 → 10 项质检。
剧本层：一句话梗概+题材+风格 → 单次 LLM(deepseek-chat temp 0.8) → 剧名/人物表/100字梗概/**分镜表(镜头序号|景别|时长秒|画面描述|台词|音效BGM)**/完整剧本/下集钩子。

## 10 项质检
通过"我想成为她吗"筛选 / 兴奋非沉重 / 核心是"她做了什么" / 标题过5铁律 / 一句话=情绪过山车 / 女主过三关 / 3概念差异化 / 覆盖不同情绪 / 喜剧公式≥3/5 / 每集有明确结构。
