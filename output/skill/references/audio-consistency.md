# 音频一致性（audio-consistency）

> 来源：comfyui-minimax-h3-audio-T8（109 节点，最硬核的工程库）+ H3 联合音画模型原理。
> H3 天然带双声道音频，但**跨镜音色/对白/背景音一致**需要显式锁定。

## H3 联合音画契约（不是"塞音频进 latent"那么简单）
T8 节点维护 ComfyUI H3 实现里这些**契约**：媒体展示顺序、`<Picture N>`/`<Video N>`/`<Audio N>` 标签、联合 AV latent、首尾关键帧、参考媒体、噪声掩码。任何音频节点都得对齐这套，不能只把源音频塞进 latent。

## 跨镜音色一致（核心）
- **显式音色库 (explicit timbre library)**：把每个角色的音色作为可复用参考（`<Audio N>` / 音色参考），跨镜锁定同一角色音色。
- **描述/参考音色** + **ASR 与身份评估**：先 ASR 识别对白，再评估说话人身份是否一致（防串戏到声音层）。
- **逐句对白 + 长文本断点**：长台词按句断点，逐句生成/校验，避免一句太长被截断/口型崩。
- **ADR（Automated Dialogue Replacement）**：对白不满意可替换重录对白轨。

## 对白安全混音
- **对白边界分析**：检测每句对白的时间边界。
- **对白安全分轨混音**：在边界处 duck/避让，保证对白不被 BGM/SFX 盖过。
- **分时背景底轨锁定**：按时间锁背景底轨（环境音/room tone），跨镜保持一致的"房间声"。

## 多人镜头的顺序修复（FaceRefine multi-person）
- **SAM3.1 分色追踪 2-3 人**（按镜头）→ YuNet + SFace 建 CPU 角色档案（清晰单人参考图）。
- 参考图默认 `dominant_face_auto`：最大框 vs 第二名需 面积比≥1.8 + 置信度差≥0.20 + 自身置信度≥0.60 才自动选，否则**拒绝**（宁拒不错选）。
- **颜色/`0:0` 索引只代表镜头内轨迹，不能当人物身份**；用户可 `{"0:0":"Character_A",...}` 逐镜头覆盖。
- **顺序生成，不并发**：不把多人同时送 H3；候选经 `previous_composite` 链式合成（默认 `accept_candidate=false` + 拒绝重叠 mask）。
- 每个修复任务 = "一个人物×一个镜头窗口"（默认 73 帧≈3s）。

## FaceRefine 诚实的产品边界（T8 明说）
- 定位 = **"重建崩坏五官"**，**不是"把模糊视频锐化"**。
- 输入脸已清楚但眼口鼻/脸型结构畸变 → 参考图 + 局部 H3 重绘可纠正结构。
- 输入本身失焦/低清/小图放大 → H3 通常**保持模糊质感**，`target_face_px` **不会凭空恢复来源中不存在的纹理**。
- 推荐统一参数：MANUAL512、`relative_to_clip 0.8/0.35`、`er_sde + simple`、Turbo 8 步、**人工完整审片**。

## 一句话决策
- 单角色跨镜音色：建 `<Audio N>` 音色库 + 对白安全混音。
- 长对白：逐句断点 + ADR 兜底。
- 多人镜头：SAM3.1 分色 + 顺序逐人修复（别并发）。
- 别指望 FaceRefine 锐化模糊源——那是纹理恢复不是五官重建。
