# 一人工作室 · 自主 agent 流程（autonomous-studio）

> 把 PLAYBOOK 十步 SOP 变成 agent 可自动编排的"一句话→成片"无人值守流程。
> 人只给一句话点子（+可选参数），agent 跑完；昂贵/创意分叉处才停下来问。

## 触发
`做一部短剧："<一句话>"`（+ 可选：题材/画幅/时长/风格/对白/语言）。
agent 先解析参数，缺省：画幅 9:16、时长 45s、有对白、对白语言=用户指定否则中文、风格按题材。

## 阶段 0 部署检查（一次性，自动）
- 探测平台（Win+NVIDIA / Mac / Linux）+ 显存。
- 选 profile（`h3_short_drama plan`）。
- 显存 <6GB → 切云端 API（OpenAI/Volcengine/MiniMax），打印 provider specs，告知用户需 key。
- 锁 4 项（画幅/时长/对白/对白语言），全程复用，**不再重问**。

## 阶段 1 创意（自动，LLM）
1. `concept` → 15 字段概念。**自动判调性**：过"我想成为她"筛选，不过→自动换角度（苦情→爽点）重写，不交给人。
2. `storyboard` → 六列分镜表 JSON（3-6 镜）。
3. `check` 跑 6 条自检。
   - **全过** → 进阶段 2。
   - **失败** → agent 自动修失败行（补强钩子/拆镜/补逐秒/补 continuity）→ 重跑自检。**最多 3 轮自动修**；仍失败 → 停下来列失败项给人（附建议）。
   - 【创意门】若用户给了明确故事/对白，直接采用；否则 agent 的自动概念**可被一键替换**（保留用户覆盖权）。

## 阶段 2 资产（自动，图生图）
- 角色卡：每主要角色 1 张 16:9 多视角参考卡（含 do-not-change 特征注）。
- 场景卡：纯环境（不含人）+ 连续性地标。
- 生成后**自动检**：角色卡身份一致（多视角同脸）、场景卡无角色泄漏。
- 【锁定门】锁定的卡若后续要改 → agent 自动警告"改卡=重生成下游全部"，给继续/取消。

## 阶段 3 逐镜生成（自动，带 QC 门）
对每镜：
1. `prompts` 编译该镜 H3 提示词（I2VA 首帧锁脸 / Ref2VA 跨镜身份）。
2. 生成 clip（provider / 本地 ComfyUI）。
3. **自动 QC**（不通过就自动回退）：
   - 对白可懂性（逐帧+音频流+可懂性 三级；有音频流≠清晰）。
   - 一致性（角色/场景对照 anchors）。
   - 无分镜 artifacts（panel 边框/标签/时序标记）。
   - 时长/采样率（32kHz）。
4. 失败走回退阶梯（强化 prompt 引用 anchors → 缩镜≤6s → 换模型 → 问用户）。
- 镜头间：尾帧链 / latent 钉接（按分镜表 continuity_type）。
- 【可并行的可并行，但同角色多镜必须串行（尾帧依赖上镜末帧）；cutaway 空镜可并行。】

## 阶段 4 长片 + 装配（自动）
- 单集>15s → 拼接（首尾帧法 或 latent 钉接；关 Turbo/Spectrum；32kHz 读采样率）。
- `assemble`：normalize → xfade → BGM（一条连续，对白 duck）→ 字幕（仅用户要）。
- 接缝验收（cross-correlation + 电平 + 采样率 + freeze）。

## 阶段 5 终审（自动 + 人签字）
- 跑 QC 清单（角色/场景/payoff/对白可懂/SFX/BGM/无 artifacts/接缝）。
- 输出终审报告（每镜 pass/fail + 证据帧）。
- 【交付门】人看终审报告 → 通过=交付 / 指某镜→agent 只重做那镜（用最新批准资产，不混新旧）。

## 自主纪律（关键）
- **不停**：能自动修的不问人；创意/锁定/交付 3 处才停。
- **最新资产**：任何重生成后，下游只用最新批准版本。
- **可回放**：每步产出落盘（P.json / 提示词 / clip / 终审报告），可中途接管。
- **成本护栏**：单集估算 ≈ $2（主要视频生成）；抽卡批量化；加速只用于非对白非链式镜头。
- **VRAM 护栏**：长 clip 自动降 canvas 而非 OOM 崩；FaceRefine 逐人串联不并发。

## 一句话
人给一句话 + 关键参数 → agent 自动跑 部署→创意(自检)→资产(锁)→逐镜(带QC门)→拼接→装配→终审 → 人签字交付。
全程 3 个人机交互点（创意替换/资产锁定/终审签字），其余无人值守。
