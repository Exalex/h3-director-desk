# 大白话→规范提示词转换（prompt-engineering-zh）

> 来源：ComfyUI-H3-Prompt-Builder《MiniMax-H3-提示词规则总结》(官方使用手册 goodcase 提炼)。
> 这是"创作层"写法，配合官方 `prompt-spec.md` 的"输出格式层"。

## 核心公式（最重要）
```
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

## 三种模式写法不同
| 模式 | 写法 |
|---|---|
| 纯文生视频 | 描述更具体：主体外观/场景/动作/风格全写；**大全景交代空间 + 中景承载动作 + 特写强调细节** |
| 图生视频 | 只传 1 张必须说清是**首帧还是尾帧**；传 2 张(首+尾) H3 **不会自动加切镜**，只补中间动作光影声音，要写自然衔接不切镜 |
| 多模态参考 | 每个素材写明角色/用途，用 @编号 指代（`@图片1 是人物参考(锁脸)，@视频1 是动作参考，@音频1 是情绪参考`） |

## 要素 1：参考素材说明
- 按上传顺序 `@图片1`/`@音频2`/`@视频3`，写明每个用途。
- 常见用途：人物参考(锁脸)/物体/场景/首帧/尾帧/关键帧/音色参考/音频复用/动作参考/运镜参考/构图参考/风格参考/故事版/视频编辑。
- **特别想保持的特征明确写出来**（一致性更好）；音频复刻人声/歌词建议把歌词原文写进提示词；无素材则整段跳过。

## 要素 2：核心创意（一句话锁全片）
必须含：主体(谁) + 地点(在哪) + 事件(做什么) + 题材/风格 + 特殊运镜。
- 默认会**切镜**；不想切镜写"一镜到底"。
- **环绕运镜写 `truck left + pan right` 或 `truck right + pan left`**，别只写"环绕运镜"。
- 切镜风格可指定：普通切镜(cut)/叠化(fade)/卡点切镜/快切。
- 例：`一位穿汉服的年轻女子(@图片1)在樱花纷飞的庭院里舞剑，古典国风，电影质感，一镜到底。`

## 要素 3：画面过程说明（按时间轴分段）
每段两部分：
- **想要** = 景别 + 内容 + 运镜 + 动作 + 台词 + 音效；以切镜为时间戳分段。
  - **台词长短要和镜头长短对齐**（口型问题大多出在这）。
  - 一句台词跨 shot → 写"接着上个 shot 继续说"（支持 J-cut / L-cut）。
  - 具体文字/Logo/标题/按钮**必须写原文**（`画面中出现英文："H3"`）。
- **不想要** = 明确排除项；不要 BGM 写 `非叙事性音乐：N/A` 或 `"non_diegetic_music": N/A`。
- 写作纪律：**少写比喻，多写看得见的画面**；台词给原文（`女子说："你来了，剑等你好久了。"`）。

## 坑清单（自查）
| 坑 | 改法 |
|---|---|
| 只写一段没分段 | 按"素材+核心创意+画面过程"三段拆 |
| 传了素材没说用途 | 补 `@图片1 是 XX 参考` |
| 想要音乐又说不要 BGM | 矛盾，删一个或按场景拆 |
| 想一镜到底却写很多分镜 | 保持一段情节描述，删【镜头N】 |
| 主角脸一致但没传图 | 必须传人物参考图并标"人物参考" |
| 提示词太短 | 至少：主体外观+场景+动作+风格 |

## goodcase 风格化写法（8 特征）
1. 开头声明基础参数（时长+画幅先写死）
2. 给参考图分配职责并枚举保持特征
3. 分镜用时间戳/Shot 编号（`[0-2秒]`/`Shot 1 — 面部极近特写`）
4. 文字类给原文+出现方式(渐入/弹出/字距展开)+时长
5. 声音单独成段（BGM 构成/节奏演进/环境音/人声）
6. 负面清单成段（不要字幕/水印/现代元素/动画感/廉价恐怖）
7. 编辑类强调"保持不变"（镜头运动/物体位置/空间遮挡/光照 100%不变，无缝融合）
8. 复杂片加"整体要求补充"段（影像风格/文字包装/律动规则/景别切换/人物规则/表演/禁止项）

## 推荐模板（可直接套）
```
【参考素材说明】
@图片1：人物参考(锁脸)，需保持：[逐条列特征]
@图片2：场景参考。  @视频1：动作参考。  @音频1：音色参考，歌词："原文"
（无素材：纯文生视频）
【核心创意】
15秒，16:9，一位穿汉服的女子(@图片1)在樱花庭院(@图片2)舞剑，古典国风，电影质感，一镜到底。
【画面过程描述】
0–3秒：全景，女子从左缓步走入庭院，背景虚化，无对白，只有脚步声。
3–8秒：切中景，拔剑起势，樱花飘落，镜头推进。
8–12秒：切特写，剑光一闪，慢动作，樱花被剑气激散。
【整体要求补充】(复杂片)
▍影像风格 ▍文字包装 ▍声音设计 ▍禁止项
非叙事性音乐：N/A
```

## 大白话→规范 转换要点
- "我要一个酷炫的视频" → 主体+场景+动作+风格+时长画幅+是否切镜
- "参考这张图" → `@图片1 是 XX 参考`，写明保持什么/不复制什么
- "加个特效" → 特效的具体样子(颜色/形态/时机/与主体关系)
- "不要背景音乐" → `非叙事性音乐：N/A`

## 硬约束补充
- **提示词 ≤7000 字符**；**详细类 350-500 英文词**（对话密集时以放下完整台词为准，不硬凑字数）。
- 参考输入上限：图≤9 / 视频≤3(每2-15s 总≤15s) / 音频≤3 / 混合≤12。
