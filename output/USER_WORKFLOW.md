# H3 短剧 · 用户工作流（小白版）

> 本文档写给「从没做过短剧」的你。读完只需要做 4 件事：
> **① 给我们一个故事 → ② 在 4 个关卡点头确认 → ③ 等成片 → ④ 验收成片。**
> 中间所有环节（写大纲、画角色卡、拆镜头、写提示词、生成视频、拼接、QC）由我们自动执行，你不需要懂任何技术细节。

---

## 1. 先搞懂一件事：这是做什么

我们用 MiniMax 的 **H3（海螺 3.0）** 模型做**带对白的竖屏短剧**。
它最大的本事：**喂一句提示词，直接出画面 + 对白 + 口型 + 音效**，不用先录音再对口型。
一集（30–60 秒）不是一口气吐出来的，而是**由 3–6 个 5–10 秒的镜头串起来**，像拍电影一样。
所以成片看起来是「短剧」，而不是一段「会抖的 AI 视频」。

---

## 2. 你必须提供的 4 样东西

开工前，你必须告诉我们这 4 样。缺了哪样，整部片都会跑偏。

| 项 | 你要告诉我们的 | 例子 |
|---|---|---|
| **故事** | 一个点子（一句话或一小段就行） | 「一个深夜女主播，突然收到她 3 年前失踪姐姐的直播私信。」 |
| **人物** | 主角是谁、长什么样 | 「小满，24 岁，圆脸，黑色低发髻，米色连帽卫衣」 |
| **时长 + 画幅** | 一集多长 + 竖屏还是横屏 | 「竖屏 9:16，一集约 45 秒」 |
| **风格** | 什么调性 / 什么视觉感觉 | 「暗黑悬疑，一盏暖台灯 vs 冷屏幕光」 |

**可选、但有的话更好：**
- 要不要对白、对白语言（默认：有对白、中文）
- 参考素材（角色参考图、参考视频、音乐）
- 想做几集（默认：先做第 1 集，做满意了再往后续）

> 你哪怕只给一句话也行——缺的部分我们会按默认值（竖屏 9:16 / 45s / 有对白 / 中文）补齐，然后在第一个确认关卡跟你再核对一遍。

## 3. 怎么把需求给我们（两种方式，任选其一）

### 方式 A：一句话输入（可直接复制，最快）

把下面这句复制、把 `< >` 里的部分填上、发给我们即可：

> **请帮我做一集短剧：<故事点子>，人物是<长什么样>，竖屏 9:16，一集约 <N> 秒，<风格> 风格，带中文对白。**

具体示例（可直接复制用）：
> 请帮我做一集短剧：一个深夜女主播，突然收到她 3 年前失踪姐姐的直播私信。人物是小满，24 岁，圆脸，黑色低发髻，米色连帽卫衣。竖屏 9:16，一集约 45 秒，暗黑悬疑风格，带中文对白。

### 方式 B：制片人模板（填得越全，越不容易跑偏）

想多控制一些细节的话，复制下面这个模板、逐条填好、发给我们：

```text
【制片人单】
· 故事点子：（1–3 句，越具体越好）
· 主角：（名字 + 年龄/长相/标志服装）
· 配角：（可选，是谁、跟主角什么关系）
· 画幅：竖屏 9:16（默认）
· 单集时长：30 / 45 / 60 秒（默认 45）
· 对白：有对白 / 无对白（默认有对白）
· 对白语言：中文（默认）
· 视觉风格：（调性、光线、年代，如「暗黑悬疑、冷暖气对比」）
· 想要的开场钩子：（可选，前 3 秒想看到什么）
· 想要的结尾悬念：（可选，结尾想留什么钩子）
· 参考素材：（可选，角色参考图 / 参考视频 / 音乐链接）
· 集数：（默认先做第 1 集）
```

## 4. 我们自动执行的 8 步（按顺序，你不用动手）

收到你的故事后，我们按下面 8 步自动跑。**你不需要懂技术细节**，只要知道「我们在替你做什么」：

1. **大纲** — 把你的故事点子扩成完整故事骨架：主角想要什么/缺什么/有缺陷、故事因果链（8 个节拍）、情感锚点在哪、对白节拍在哪。
2. **角色卡**（含**锁角色**）— 给每个主要角色画一张「角色卡」参考图（多角度 + 表情 + 不能变的特征），并**把脸/服装锁成硬锚点**，保证这个人物后面跨镜头不会「变脸」。
3. **场景卡** — 给每个地点画一张「场景卡」（纯环境、不含人）+ 固定地标（门框/灯/窗），保证背景前后一致。
4. **拆分镜** — 把这一集拆成一张「分镜表」：每个镜头几秒、什么景别、每秒发生什么、人物在哪、地标在哪、声音和对白是什么。
5. **写提示词** — 给每个镜头写一句模型能直接执行的「H3 提示词」（画面 + 对白 + 口型 + 音效，一条 prompt 全出）。
6. **逐镜生成**（含**尾帧接续**）— 把每句提示词逐镜喂给 H3 生成视频片段；每镜生成后自动 QC（口型/一致性/无分镜表残留）。**尾帧接续**：把上一镜的最后一帧，作为下一镜的起始帧，整集接得起来、不「跳」。
7. **拼集** — 把整集串起来，铺一条**连续 BGM**（BGM 在对白处自动压低），镜头之间加 0.4 秒转场。
8. **QC** — 交付前跑终审：角色一致性 / 场景连续 / 对白是否清晰 / 音效同步 / BGM 平衡 / 无分镜表残留 / 接缝不跳。

> 全程每一步的产物都会**落盘**（大纲 / 角色卡 / 分镜表 / 提示词 / 成片片段 / QC 报告），你随时可以喊「接管看看」。

## 5. 为什么要拆成 5~10 秒的镜头？

不是炫技，是因为**短镜头更稳、更好修、更好看**：

- **模型对短镜头更稳**：H3 在 4–15 秒内表现最好，5–10 秒是甜区，人物脸、口型、动作最不容易崩。
- **单镜出错面小**：一个镜头越短，一次能出问题的地方越少（脸漂/场景漂/口型错位），也更容易定位是哪一秒出的问题。
- **重做更便宜**：某镜失败，只需要重做那 5–10 秒，不用重做整集，重做成本很低。
- **节奏更「短剧」**：短剧讲究每 15–20 秒一个情绪点、快切留人。5–10 秒一个镜头，才能自由地用特写/空镜/反应镜头交替，不拖沓。
- **更好保持一致性**：每个镜头短到「角色卡 + 场景卡」能罩得住；再配合镜头之间的尾帧接续，整集才连得起来、不串戏。

> 一句话：**把大的拆成小的、逐个小镜头生成、再把小镜头拼成大集**——这是做 AI 短剧最稳的路子。

## 6. 一集 30~60 秒是怎么由多个镜头组成的

一集**不是一条长片**，而是**3–6 个 5–10 秒的镜头串起来**：

- 30 秒一集 ≈ 3–4 个镜头
- 45 秒一集 ≈ 4–5 个镜头
- 60 秒一集 ≈ 5–6 个镜头

每个镜头负责一段剧情。一集的典型结构：

| 顺序 | 作用 | 内容 |
|---|---|---|
| 镜头 1 | **开场钩子** | 前 0–3 秒抓人（冲突/悬念/打脸） |
| 镜头 2 | **升温** | 冲突升级、人物进场、关系建立 |
| 镜头 3 | **反转/爽点** | 揭秘/反转/爽点（这一集的戏眼） |
| 镜头 4 | **反应/空镜** | 反应特写、空镜过渡（顺便藏「接缝」） |
| 镜头 5 | **结尾悬念** | 最后一句/最后一帧必是钩子，让人想点下一集 |

**拼接过程**（全自动，你不用管）：
1. 每个镜头单独生成（带角色卡、场景卡、上一镜尾帧）；
2. **尾帧接续**：上一镜的最后一帧 = 下一镜的第一帧，保证接得上；
3. **拼集 + BGM**：所有镜头顺序拼接 + 一条连续 BGM（对白处压低）+ 0.4s 转场；
4. **QC**：检查接缝、音频、一致性。

所以一条「45 秒一集」，其实是 [镜头1 开场钩子] → [镜头2 升温] → [镜头3 反转] → [镜头4 反应] → [镜头5 悬念] 这 5 个镜头的链条。

## 7. 提示词逻辑示例：第一集 vs 第二集

先说个常识：**每个镜头都有一条「提示词」**——就是我们喂给 H3 的那段文字，告诉它「画面长什么样、对白是什么、口型怎么动、音效是什么」。
做连续剧时，第一集和第二集的提示词逻辑**完全不同**：

### 第一集：逻辑是「立」（从头介绍）
- 人物首次出场 → **完整描述**（脸、发型、服装、标志物，一条条写清楚）。
- 场景首次出场 → **完整描述**（地标在哪、光线怎样）。
- 第一个镜头通常用角色卡当起始帧（I2VA 锁脸），把脸「钉住」。
- 故事自成一体：自己的开场钩子 → 中段 → 结尾悬念。

拿《午夜来电 · 第一集》第 1 镜举例，提示词大致是：
> 风格：暗黑悬疑、冷暖气对比、轻微颗粒
> [镜头1] 小满在直播，语气亲切；桌上的手机亮起、震动。
> 0–3s：小满对镜头笑、比划（对白：「家人们，今天的礼物我全收下了啊，谢谢！」）
> 3–6s：手机亮起，震动声压过房间音
> 6–10s：小满瞟向手机，笑容凝固（对白：「诶？这谁啊……」）
> 角色：小满（脸/发髻/米色卫衣——锁定，不变）
> 场景：直播房间（台灯在左 1/3、笔记本居中、城市窗在上）

### 第二集：逻辑是「续」（不重描、接着拍）
- 人物**不再重新描述**：脸/服装已经锁定，提示词里只用「短名 + 锁定引用」，不重复写。
- 开场明确**接第一集结尾**：第一镜的「连续性交接」写「接上一集末帧：小满瞪着手机上姐姐的私信，惊恐」。
- 场景/光线/风格/画幅/时长**全部不变**（复用锁定好的卡）。
- 故事推进到新的节拍：新的冲突、新的对白、新的结尾悬念。

拿《午夜来电 · 第二集》第 1 镜举例，提示词大致是：
> [接第一集末帧] 小满手在抖、拿着手机，仍在直播房间。
> 0–3s：小满拨出电话，房间安静
> 3–6s：电话接通，传来一个声音（对白：「姐姐……你在哪？三年了。」）
> 6–10s：对方声音，正是 3 年前「已故」的姐姐；小满瞳孔震动
> 角色：小满（脸/发髻/米色卫衣——沿用第一集的锁定卡，不重描）
> 场景：直播房间（与第一集同地标、同光线，不重描）

### 两者核心区别（一张表看懂）

| | 第一集 | 第二集 |
|---|---|---|
| 人物 | 完整描述（首次出场） | 短名 + 锁定引用（不重描） |
| 场景 | 完整描述（首次出场） | 复用（不重描） |
| 开场 | 自己的开场钩子 | **接第一集末帧/结尾状态** |
| 故事 | 独立的开场→中段→悬念 | 推进到下一节拍、新悬念 |
| 脸/服装/光线/风格 | 第一次锁定 | **沿用锁定资产，保持不变** |

> 一句话：**第一集是「把人和调性立起来」，第二集是「接着第一集拍、人还是那个人」。**
> 所以角色卡和场景卡必须「锁定」——这样第二集的小满，才会是第一集的小满。

## 8. 四个需要你确认的关卡（确认门）

我们全程只在 **4 个地方**停下来、等你点头才继续。之前都是自动的，不打扰你：

| # | 什么时候确认 | 我们给你看什么 | 你要决定什么 |
|---|---|---|---|
| **关卡 1：方向/故事确认** | 大纲做完后 | 故事骨架、主角设定、时长/画幅/风格/对白设定 | 方向对不对？（不对就告诉我们改，改完再确认，不额外收费） |
| **关卡 2：角色/场景资产锁定** | 角色卡 + 场景卡画好后 | 每个角色的卡、每个场景的卡 | 脸/服装/背景满意吗？**一旦锁定，人物就定了**；之后要改我们会先警告你「改卡=下游全部重生成」 |
| **关卡 3：分镜/提示词确认** | 分镜表 + 提示词写好后 | 每镜几秒、每镜干什么、对白在哪、钩子怎么排 | 节奏/结构 OK 吗？（某镜不满意就点名调整那一镜） |
| **关卡 4：成片签字** | 拼集 + QC 完成后 | 成片视频 + QC 报告（每镜 通过/不通过 + 证据帧） | 通过 → 交付；指出哪镜不对 → 我们只重做那一镜（用最新资产，不混新旧） |

> 说明：4 个关卡之间，我们**不会拿鸡毛蒜皮的事打扰你**。只在这 4 处（贵、创意分叉、最终）才停。

## 9. 责任边界（谁负责什么）

### 你负责
- 提供**故事 / 人物 / 时长画幅 / 风格**（整部片的原料）；
- 在 4 个确认关卡做**创意决策**（方向对不对、脸满不满意、结构行不行、成片片不过关）；
- **最终验收**：成片最终是否可用，由你拍板；
- 有参考素材（角色图/参考视频/音乐）就提供给我们；
- 理解：AI 有天然随机性，我们保证「过程可控、一致性有检」，但**不保证每个镜头都一次做到影视级完美**。

### 我们负责
- 从大纲到成片的全流程执行（上面 8 步）；
- **一致性**：角色/场景锁定、跨镜头/跨集一致、QC 检查；
- **技术质量**：口型、无分镜表残留、接缝验收、音频采样率（32kHz）等坑的处理；
- **成本控制**：单集 30s ≈ $2（主要是视频生成），重做只重做那镜、不重做整部；
- **不静默混新旧**：任何资产重生成后，下游只用「最新已确认版本」，绝不把新旧资产混进成片。

### 我们不做（边界）
- 不擅自改你**已确认的创意方向**（只问、不替你拍板）；
- 不**静默混用**「已确认」和「未确认」的资产进成片；
- 不保证每个镜头都「完美」（AI 有随机性，某镜失败会走回退：强化提示词 → 缩镜 → 换模型 → 问你，不硬凑）；
- 不加字幕/文字，除非你明确要；
- 超出你预期的事（例如影视级真人质感、指定某位明星的脸），我们会提前说做不到，不硬接。

### 一句话总结
> **你决定「做什么、满不满意」；我们负责「怎么做、怎么保持一致、怎么做稳」。**
> 双方在这 4 个关卡上共同把关，就把一部短剧稳稳做出来。
